## Changes

- Constrain the transitive AndroidX Fragment dependency from Play in-app updates to 1.9.1.
- Remove redundant system-bar setters and restrict the legacy divider setter to API 29–34.
- Use cutout mode `always` in the startup theme on API 30+.
- Lift New/Edit Alarm sheets as a single surface with a 250ms keyboard transition.
- Use 120dp time-wheel viewports on phones shorter than 900dp; retain 184dp elsewhere.

No foreground-service classification, alarm scheduling, permissions, SDK or toolchain versions change.
