## Expressive Clock v0.1.9

This update restores the original expanded Timer and Stopwatch island design while keeping it responsive on compact phones, and makes the bottom navigation respond directly to page swipes.

### Dynamic Island
- Restore the left-aligned time and caption with three scalloped controls on the right, matching the original visual hierarchy.
- Fit readouts and controls into separate measured regions, with responsive padding, button sizing and comfortable touch targets.
- Improve long-duration and enlarged-font layouts, with a compact variation for exceptionally narrow cards.
- Restore the original default expanded-card proportions and retain additional height where accessibility text needs it.
- Remove unnecessary top space when Overlap camera cutout is selected.
- Preserve compact collapsed time formatting, borderless styling, calibration profiles, saved offsets and existing animation specifications.

### Navigation
- Make the bottom-bar indicator follow horizontal swipe progress immediately, including partial swipes and snap-back.
- Keep icons and actions synchronised with the page being viewed.
- Handle rapid dock taps and swipe-interrupted navigation without leaving stale navigation requests behind.
- Preserve the existing unfolded two-pane navigation path.

### Verification
Automated debug/release builds, unit tests, lint and Python regression checks passed. Physical development checks used a Galaxy S25 and Pixel 11 Pro Fold. Expanded-card testing included short and long values, local 2x font overrides, narrow card constraints, folded landscape and unfolded portrait. Timer/Stopwatch action and expansion checks used the production composables in a debug-only host without altering persisted timers. S25 main-app navigation checks covered forward/back swipes, partial reversal, rapid taps, interrupted navigation and vertical scrolling. Physical unfolded-landscape and the exact Galaxy S26 / Android 17 / One UI 9 configuration were not verified in this pass. This release does not claim universally smooth 120fps rendering.

Thanks to everyone sharing device feedback. Production package and signing identity are unchanged. Google Play upload is handled separately by the maintainer.
