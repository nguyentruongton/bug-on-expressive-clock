## Expressive Clock v0.1.10

This focused update improves swipe navigation on foldables and brings the existing bottom-bar icon animations to page swipes.

### Navigation
- Enable horizontal swiping between Alarms, World Clock, Timer and Stopwatch when unfolded.
- Preserve the unfolded Alarm and World Clock two-pane layouts.
- Remove hidden pane touch blockers that prevented swipes over parts of the unfolded screen.
- Keep the bottom-bar indicator following swipe progress immediately in both compact and unfolded layouts.
- Play the existing icon animations when a swipe selects a tab, while preserving repeat-tap animations and avoiding double animation triggers.
- Retain the Timer draft and selected World Clock city when navigating between pages.

### Verification
Debug and release builds, unit tests, Android lint and Python regression checks passed. Physical checks used a Pixel 11 Pro Fold on Android 17, folded and unfolded in portrait. Checks covered navigation through all four destinations, swipe-triggered icon animations, repeat taps, partial-swipe snap-back, vertical gestures and selected state. Unfolded landscape, broader running alarm/widget checks and other physical devices were not re-tested for this release.

Thanks to the community for the helpful feedback. Application ID and production signing identity are unchanged. The existing Play Console boot/foreground-service warning remains under investigation and is not claimed as fixed. Google Play upload is handled separately by the maintainer.
