## Expressive Clock v0.1.8

This maintenance update improves floating Timer and Stopwatch positioning and adds more flexible calibration. Thank you to @pramodbeema and the GitHub community for the detailed device feedback.

### Dynamic Island
- Keep the floating island top-aligned when another app rotates into landscape, using current display metrics and rejecting side-edge camera cutouts as top anchors.
- Improve positioning around shallow camera cutouts and keep expanded cards compact in landscape.
- Restore background overlays after accessibility-service restarts without waiting for the main Activity.
- Animate one-minute Timer additions with upward mechanical digit movement.
- Preserve the intentional compact time format and borderless black appearance.

### Calibration
- Add independent folded portrait, folded landscape, unfolded portrait and unfolded landscape profiles on foldables; standard phones show Portrait and Landscape.
- Preserve existing calibration when migrating and support fractional slider values with precise 1dp arrow adjustments.
- Add Left/Centre/Right alignment, per-profile enablement and expanded-card placement options.
- Centre the default vertical-slider position and map each side to available on-screen travel.
- Preview edits locally, with matching Reset/Save buttons and Save/Discard/Keep editing prompts for unsaved changes.
- Add animated guidance when opening an inactive display profile, with Continue Anyway and automatic opening when the display matches.
- Add predictive-back page transitions, animated selection highlights and progressive scroll-edge blur/falloff.
- Keep calibration previews available independently of the accessibility-service window token.

### Orientation and contributor builds
- Keep the main app portrait-only on standard slab phones, with a temporary rotation exception for calibration pages. Foldable/tablet rotation remains available.
- Allow debug builds, tests and lint without private production signing credentials. Production release packaging still requires production credentials and never falls back to debug signing.

### Verification and limitations
Automated debug/release builds, unit tests and lint were run for this release. Development testing included a Galaxy S25 (Android 16 / One UI 8.0) and Pixel 11 Pro Fold (Android 17), including landscape overlays and foldable profiles. The complete device matrix was not repeated after every final UI refinement. The exact base Galaxy S26 / Android 17 / One UI 9 configuration has not been physically verified. Calibration animation frame drops remain observable in debug performance measurements; this release does not claim universal 120fps rendering. Manual calibration can intentionally move the pill over system icons.

Production application ID and signing identity are retained. Google Play upload is handled separately by the maintainer.
